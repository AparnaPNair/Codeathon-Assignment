# Codeathon-Assignment
📊 Sales Analysis Dashboard
🚀 Power BI | Data Analytics Project
📌 Project Overview

This project presents an end-to-end Sales Analysis Dashboard built using Power BI, designed to transform raw data into meaningful business insights.

It provides a comprehensive view of sales performance, customer behavior, and product efficiency, enabling data-driven decision-making.

🎯 Business Objectives
📈 Analyze overall business performance
👥 Understand customer behavior and spending patterns
🛒 Identify top-performing and underperforming products
💡 Generate actionable insights and recommendations
📂 Dataset Information

The dataset includes key business attributes:

Order ID – Unique transaction identifier
Customer Name – Buyer details
Product Name – Items purchased
Category – Product classification
Sales – Revenue generated
Profit – Earnings after cost
Quantity – Units sold
Order Date – Transaction timeline
Region – Geographic location
🧹 Data Preparation

Data cleaning and transformation were performed using Power Query:

✔ Removed null and duplicate records
✔ Standardized formats and values
✔ Converted data types (Date, Numeric, Text)
✔ Handled missing values effectively
✔ Resolved inconsistencies (e.g., "Unknown" customers)

📈 Key Insights
💰 High revenue but low profit margin (~5–6%)
👥 Revenue is concentrated among a few customers
📉 Customer engagement is declining over time
⚠️ Some products show high sales but low profitability
📊 Sales trend is inconsistent
🧹 Data quality issue identified ("Unknown" customer)
💡 Business Recommendations
🚀 Improve profit margins through pricing and cost optimization

🛒 Promote high-profit products
⚖️ Reduce dependency on a small customer base
🧹 Improve data quality and tracking systems
🌍 Focus on high-potential regions
