# Codeathon-Assignment#
📊 Sales Analysis Dashboard  

---

## 📌 Project Overview

This project presents an **end-to-end Sales Analysis Dashboard** built using **Power BI**.

It provides insights into **sales performance, customer behavior, and product efficiency**, enabling **data-driven decision-making**.

---

## 🎯 Business Objectives

- 📈 Analyze overall **business performance**
- 👥 Understand **customer behavior and spending patterns**
- 🛒 Identify **top-performing and underperforming products**
- 💡 Generate **actionable insights and recommendations**

---

## 📂 Dataset Information

The dataset includes:

- **Order ID** – Unique transaction identifier  
- **Customer Name** 
- **Product Name**  
- **Category**  
- **Sales**  
- **Profit**  
- **Quantity** 
- **Order Date**  
- **Region**  

---

## 🧹 Data Preparation

- ✔ Removed null and duplicate records  
- ✔ Standardized formats and values  
- ✔ Converted data types (Date, Numeric, Text)  
- ✔ Handled missing values  
- ✔ Cleaned inconsistent entries (e.g., *"Unknown" customers*)  

---

## 🧮 Key Metrics (DAX)

- **Total Sales**  
- **Total Profit**  
- **Total Orders**  
- **Total Customers**  
- **Average Order Value (AOV)**  
- **Profit Margin (%)**  

---

## 📊 Dashboard Structure

### 🟦 Overview Dashboard

- KPI Cards: **Sales, Profit, Orders, Customers**  
- 📈 Sales Trend Analysis  
- 📊 Category-wise Sales  
- 🌍 Region-wise Performance  

---

### 👥 Customer Analysis Dashboard

- 🏆 Top Customers by Sales  
- 🔁 Customer Purchase Frequency  
- 💰 Average Spend per Customer  
- 📊 Customer Distribution  

---

### 🛒 Product Analysis Dashboard

- 🥇 Top Products by Sales  
- 📉 Profit vs Sales Analysis (Scatter Chart)  
- 📊 Category Performance  
- 📦 Quantity Trend  

---

### 🔍 Drill-Through Analysis

- Enables **deep dive into product-level insights**  
- Improves **interactive user experience**  

---

## 📈 Key Insights

- 💰 High revenue but **low profit margin (~5–6%)**  
- 👥 Revenue concentrated among **few customers**  
- 📉 **Customer engagement declining**  
- ⚠️ High sales but **low profit products exist**  
- 📊 Sales trend is **inconsistent**  
- 🧹 Data issue: **"Unknown" customer present**  

---

## 💡 Recommendations

- 🚀 Improve **profit margins**  
- 🎯 Strengthen **customer retention**  
- 🛒 Promote **high-profit products**  
- ⚖️ Reduce dependency on few customers  
- 🧹 Fix **data quality issues**  
- 🌍 Focus on **high-performing regions**
